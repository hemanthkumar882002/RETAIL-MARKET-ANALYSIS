# Retail Market Analysis

## Project Overview

This project focuses on analyzing retail market data to identify customer purchasing patterns, product performance, and business trends.

The analysis was performed using SQL and Power BI to transform data into meaningful business insights and interactive dashboards.

## Objectives

- Analyze customer purchasing behavior
- Identify popular and least-purchased products
- Analyze product, aisle, and department performance
- Understand ordering and purchasing patterns
- Analyze customer reordering behavior
- Create interactive Power BI dashboards for business analysis

## Tools & Technologies

- SQL / MySQL
- Power BI
- DAX
- Power Query
- Git & GitHub
- Git LFS

## Analysis Performed

The project includes analysis of:

- Customer purchasing behavior
- Product performance
- Department and aisle performance
- Order patterns
- Frequently purchased products
- Least purchased products
- Customer reorder behavior
- Basket/order analysis

## Power BI Dashboard

The Power BI report contains multiple dashboards designed to provide insights into retail purchasing patterns and business performance.

Dashboard screenshots are available in the `Dashboard` folder.

The complete Power BI report is available in the `PowerBI` folder.

## Key Insights

The dashboards provide insights into:

- Customer purchasing patterns
- Product demand
- Department and aisle performance
- Frequently and least purchased products
- Customer reorder behavior
- Order and basket characteristics
